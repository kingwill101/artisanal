# Layout Breakpoints

```bash
dart run example/tui/examples/layout-breakpoints/main.dart
```

This example demonstrates responsive behavior using `ResponsiveBreakpoints`,
including:

- `resolve` to get the active breakpoint.
- `isAtLeast` to switch to split layouts.
- `isBelow` to branch before a threshold.

Press `p` at runtime to toggle between default and compact profile thresholds.
