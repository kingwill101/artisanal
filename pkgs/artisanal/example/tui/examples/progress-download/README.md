# Download Progress

This example demonstrates progress updates with a [Progress Bubble][progress].

In this Dart port, progress updates are emitted as custom
`DownloadProgressMsg` messages and handled in the model update loop.

## How to Run

Run from the package root:

```bash
dart run example/tui/examples/progress-download/main.dart
```
