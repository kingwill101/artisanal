# Unicode: Expected Glyphs

- Latin: café naïve résumé — voilà
- Greek: α β γ Δ Ω π λ
- Cyrillic: Привет мир — Москва
- Arrows: ← ↑ → ↓ ↔ ⇢
- Symbols: § ¶ © ® ™ ✓ ✗ ± ≈ ≠

The marker remains ASCII for easy capture comparison.
