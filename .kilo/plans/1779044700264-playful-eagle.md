# Plan for Enhancing Code Review Inline Comment Highlighting

## Problem Analysis
The current implementation already has infrastructure for showing review comments inline in the diff view via the `commentHighlights` mechanism in `GitDiffModel`. However, the visual highlighting may not be prominent enough to match GitHub's inline review blocks.

## Observations
1. The `_selectedFileDiff` function in `detail_pane.dart` correctly:
   - Maps review comments to render lines
   - Creates `DiffCommentLineHighlight.thread` highlights for each comment
   - Combines these with existing highlights and passes to `GitDiffViewer`

2. The `GitDiffModel` already supports rendering comment highlights through its viewport

3. The `DiffStyles` class defines styles for comment threads:
   - `commentThreadLine` and `commentThreadGutter`
   - But these may not be visually prominent enough

## Solution Approach
Enhance the visual prominence of review comment highlights in the diff view by:

1. Updating the default `DiffStyles` to use more noticeable background colors for comment threads
2. Ensuring the highlight mechanism works correctly for all review comment types
3. Verifying the comment-to-render-line mapping is accurate

## Implementation Steps

### 1. Enhance Comment Thread Styles
Modify `DiffStyles` constructor and `light()` factory to use more prominent colors:
- Change comment thread background from `#fff0c2` to a more visible yellow (e.g., `#ffffcc` or `#ffeb3b`)
- Update dark theme accordingly
- Consider adding a border or stronger foreground color for better contrast

### 2. Verify Comment Mapping
Ensure `mapReviewCommentsToRenderLines` function in `diff_comment_mapper.dart` correctly:
- Maps review comments to the appropriate rendered lines
- Handles multi-line comments properly
- Works across all diff view modes (unified, side-by-side, pretty)

### 3. Consider Active Comment Highlighting
Optionally add support for highlighting a specific comment when referenced (e.g., from comments list):
- Could use `selected` highlight kind for temporarily emphasized comments
- Would require coordination between comment list and diff viewer

## Files to Modify
- `pkgs/artisanal/lib/src/tui/bubbles/git_diff.dart` - Update DiffStyles for better comment thread visibility
- Potentially: `pkgs/artisanal_widgets/example/github_cli/lib/src/ui/dashboard/detail_pane.dart` - Verify comment mapping usage

## Testing Considerations
- Verify highlights appear in all diff view modes
- Check that highlights don't interfere with text readability
- Ensure performance isn't significantly impacted
- Test with various comment types (single-line, multi-line, threaded)
